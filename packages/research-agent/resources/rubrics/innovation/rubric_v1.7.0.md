# 论文创新性评估规范（目标任务可指定）

版本：**1.7.0**｜满分：**10分**｜步长：**0.5分**｜状态：**通用任务评分修订版，尚未经跨领域专家数值校准**

本版基于[v1.6.0](rubric_v1.6.0.md)修订：**用户在使用时指定目标任务**；各类别上限仅约束**主导创新自身**，独立次要贡献奖励`J`在主导贡献封顶后额外计入；C8基础分区间改为6.0–7.0。除上述变化外，查新、证据核验、去重、其他子类基准分和主线限制维持原规则。历史评分不自动重算，修订规范本身不等于对任何具体论文完成查新。

> **强制要求：创新性评估必须实际联网搜索，并经过多轮反证与交叉核验。未完成联网查新与复核，不得给出数值创新评分。**
>
> **评分定位：**本规范评价论文的**原创性及其技术／概念实质**，并非投稿接收概率、论文综合质量、历史影响力或引用次数评分。主流会议的审稿意见可帮助校准判断原则，但不能把其综合评分直接视为本规范的10分制“标准答案”。

## 1. 评估范围

评价**本次指定目标任务**中的**算法创新、理论创新、问题定义与（适用时）威胁建模创新**。不依据实验指标高低、性能提升幅度、数据规模、算力、工作量、作者身份或发表场所加分。实验和证明只用于核验创新主张是否成立（第2.5节），而不以结果大小额外加分。本领域和跨领域复用均须考察源想法／模块的新颖性与必要技术复杂性，并按第3节在所属子类区间内定分；这不是额外的复杂度奖励。

**任务配置：**每次评估由用户指定`target_task`（研究领域、任务或具体问题），并依据被评论文明确任务目标、输入／输出、约束、适用条件和必要的子任务边界；评估者不得为了制造“首次”或避开先例而任意缩窄任务范围。**本领域**指该目标任务所属领域及其近邻分支，查新还应覆盖实质等价的跨领域问题。目标任务尚不明确且足以影响查新或定类时，先要求澄清；仍不能确定则`assessment_status=insufficient`、`score.S=null`。

更换数据类型、应用场景、任务名称或领域内子方向，**不自动**构成跨任务迁移。其他任务可以作为外部技术来源，但来源所属学科或距离**不直接决定分值**；应检查迁入后针对目标任务发生了什么实质变化。

必须记录：被评论文及其版本、比较时点、同一问题中已知的最接近方法、问题／威胁定义和理论。回溯原创性时，不用比较时点之后才出现的研究倒推否定先前贡献；也不以论文后来的影响力反向抬高原创分。

**原则：**评价“新增了什么不可由先前工作直接得到的认识或计算关系”，而不是“使用了多新、多远、多复杂的术语或组件”。

## 2. 前置判定

### 2.1 强制联网查新与多轮复核

**本节是数值评分的强制前置条件，优先于后续计分规则。不得仅凭模型记忆、论文自述、用户提供的参考文献或一次关键词搜索判断创新性。**

每次评估必须实际联网，围绕每个核心贡献完成至少三轮有实质差别的检索与核验。 对问题／威胁建模贡献，检索对象还须包括先前的任务定义、攻击者能力、成功判据、反例、评价协议及相邻领域中的等价问题，而非只检索算法名称。后续轮次须利用前一轮发现调整关键词、术语和比较对象；重复同一查询或把一次批量搜索拆成多项，不算完成多轮复核。

| 轮次 | 目的 | 必须完成的核验 |
|---|---|---|
| 第一轮：建立比较基线 | 找到最接近的已有工作 | 使用问题、机制、同义术语及中英文关键词，检索目标任务的各相关分支、实质等价问题和可能的外部来源任务 |
| 第二轮：主动反证 | 尝试推翻“首次”“新机制”或“新理论”的暂定判断 | 查找同构方法、不同命名、早期工作及已有迁移；理论贡献须比较命题、假设、界限和证明方法 |
| 第三轮：原文交叉核验 | 复查关键差异并修订结论 | 阅读最接近原始工作的关键方法、公式或证明，追查相关引文，以新发现的术语补搜，重新确认类别、上限和分数 |

检索与论证要求：

- 优先核验原始论文、预印本、正式技术报告及作者公开技术资料。不能只凭搜索摘要或二手概述认定重复或高度原创。
- 同时记录支持新增的依据、最接近的反例及排除反例的理由；没有找到反例时如实记录检索范围，不得编造反例或来源。
- 不得把领域知名度、论文标题中的“首次／统一／可证明”、后续引用量或示例锚定分数当作查新证据。
- 达到三轮不自动等于查新充分。关键冲突仍可能影响定类时，必须继续有针对性地检索；无法解决时标为暂定或无法判断，不强行下结论。
- 保留检索日期、分轮查询词、实际读取的来源与位置、关键比对结果，以及结论或分数的修订原因。“已反复思考”不能替代可核验的检索记录。

**原文无法获取时的处理：**

- **被评论文本身**的核心方法、公式或证明无法取得：assessment_status=insufficient，总分为null。
- **最接近的先前工作**无法取得全文（付费墙、失效链接等）：摘要、引文语境和二手概述只能用于定位候选，不能据此认定重复或排除反例。若该工作可能改变定类，评估状态最高为provisional，并在uncertainties中列明该文献及其可能影响；若可合理判断其不影响定类，须写明理由。

**未实际联网，或因联网失败等原因未完成上述复核流程时，必须返回assessment_status=insufficient，创新性总分为null。不得用模型记忆或内部自检补足流程，也不得输出包括0分在内的数值总分。**

### 2.2 重复贡献归零

1. 相同或实质等价的贡献已用于目标任务或实质等价的问题，且没有新的问题适配、组合关系、结构、机制或理论时，该项记0分。不能仅因模块已有，就把其针对不同问题的实质适配一并归零。
2. 改名、换符号、等价改写、换数据和常规调参，不构成有效新增。
3. 部件已有，不代表新的组合关系、任务适配、机制或理论也已有。
4. 算法重复但有新理论时，算法项0分，理论继续评价。
5. 同一贡献不能拆成多个模块、公式或引理重复计分。
6. 没有完全相同的先前工作只是必要条件，无实质意义的变化仍可0分。

比较具体计算关系、变量、假设和证明方法，不能只看名称或公式外观。每项判断应注明论文位置、最接近的先前工作及实质差异。所有引用与比较必须基于实际取得的材料，不得编造文献或首创事实。

### 2.3 整篇创新主线

> 具体技术问题或待刻画的现象 → 旧方法／旧建模的关键障碍 → 核心新增思想 → 可核验的算法、理论或问题／威胁模型贡献

主线成立需要：

- **问题具体**：指明任务约束、处理／训练／推理／决策环节、相关参与者能力或待解释现象，不能只有“更准确”“更鲁棒”“更安全”。
- **障碍明确**：指出既有规则、建模假设或威胁模型为何不足，以及不足发生的条件。
- **思想集中**：用一句话表达核心新思想，不能只有组件清单。
- **贡献连贯**：主要结果围绕同一问题或相互依赖的子问题，且有可核查的逻辑关系。

**已有部件不等于已有路线。**应比较组成部件之外的表示方式、变量角色、信息注入与观测位置、条件依赖、闭环关系，以及这些关系是否已经在先前工作中出现。若新组合形成不可约的计算关系，可进入D类；若建立真正的新基本建模／表示原则，才可能进入E8及以上。不能只因为“端到端”“生成式”“统一框架”等表述就自动给E类。

**只有新问题定义或威胁模型、尚无新算法的论文，也可以拥有完整主线**：其输出是可区分旧问题、能产生新判别或新限制的问题形式化，而非必须是一段新代码。

主线根据实际逻辑判断，文章表达不佳不等于没有主线。只有承担关键作用且通过有效性核验的贡献才能决定整体档位。

若实际只是零散拼装、无法形成共同问题与思想，重新按局部、组合或局部理论贡献定分，**整体最高4分（第5.3节公式中的M），但4分不是保底分**。材料不足时不得直接认定主线不成立。

### 2.4 信息不足与无效贡献

以下计分处理以完成第2.1节的联网查新与复核为前提。

- **已确认重复或无有效新增**：对应贡献0分；全部如此时总分0分。
- **部分内容可判断**：可给暂定分，注明依据范围与未决事项。
- **核心内容不足以定类**：分数与上限为null，不强行打分。
- **已发现明确错误、循环论证，或按第2.5节判定为无效**：该项不作为有效贡献，不能担任主导贡献，也不能参与联合修正。

“未检索到”不等于“全球首次”；模型未完成核验或未理解证明，也不等于贡献重复或错误。

### 2.5 有效性核验最低标准

有效性核验只回答：**所声称的新增机制、理论结论或问题定义是否成立，且其成立范围是什么。**它不以性能提升幅度、引用量或接受情况计分；也不因结果小而直接减分。不要求评估者亲自完成大规模复现，但须核对支撑核心声称的原文证据。

**算法贡献。**须区分两个问题：（a）论文是否真的实现了该新计算关系；（b）证据是否支持它产生了所声称的作用。

1. 优先核对隔离机制的消融／控制实验，比较时其他关键条件尽可能一致；或核对能直接推导机制作用且具有可检验后果的形式分析。
2. 架构图、代码和公式的一致性能够证明**实现了什么**，但**代码存在本身不能证明其因果有效性**。纯结构性贡献如只主张改变信息路径，可由实现核验支持这一事实；如另主张新路径带来特定效果，仍需相应证据。
3. 若同时改动多个环节，必须尽可能区分主导新关系和常规协同部件。无法区分时可暂定定类，但不得把全部提升归给该机制。

| 核验结果 | 处理 |
|---|---|
| 隔离对照、直接形式分析或可核验的结构事实支持声明的核心作用 | 正常定类计分 |
| 只有整体指标或实现代码，尚不能区分核心机制的作用主张 | 可以按已证实的结构事实暂定定类；若该作用主张是定类关键，`assessment_status`最高为`provisional` |
| 有充分对照证据显示该机制不承担其被宣称的关键作用，且排除了明显的统计功效／实现问题 | 按实际机制重新定类；确已无有效新增的部分不计分 |
| 仅“未检出显著增益”，样本不足或不确定性很大 | **不得直接等同于证明机制无效**；记录不确定性，状态最高为`provisional` |
| 机制有效，但原因与论文解释不同 | 按实际可确认的计算关系重新定类 |
| 文中叙述、公式与实现冲突，影响核心关系且无法判定 | `insufficient`；能确定实际机制时按其定类，最高为`provisional` |

**理论贡献。**

- 核对命题、量词、攻击者能力、先验知识、假设、证明关键步骤和结论适用范围。
- 若仅能证明受限模型中的结果，按**受限模型下的实际结论**评定；不得把“特定数据分布、距离约束或攻击模型下的保证”写成“所有场景普遍成立”。
- 关键步骤不能核实时最高`provisional`，不能因为看不懂或缺乏重现就武断归零。
- 已有定理的直接代入或等价改写为重复；确有新证明技术、非平凡新结论时按E1—E7评价。高档E9—E11有额外门槛（第3.5节）。

**问题定义与威胁建模贡献（P类）。**

- 明确系统边界、参与者或环境条件、可用信息、任务目标（及适用时的攻击／防护目标）、成功判据和旧模型覆盖不了的情况。
- 至少给出可复核的**非等价论证**，以及反例、形式推导、对照案例或充分具体的可检验条件，证明新定义不只是重命名。
- 问题／威胁条件必须自洽且不是专门捏造的必败情形；应如实说明其现实适用边界。**不强制要求新算法、神经网络消融或大规模实验。**
- 若声称“普遍失败”“不可能防御”，核验相应的量词与范围；单个攻击示例不能推出普遍不可能性。

**状态与分值分离：**`complete`表示关键资料和证据已足以判断；`provisional`表示可暂定但存在可能影响结论的不确定性；`insufficient`表示不能可靠定分。置信度另行报告，不对分数乘以模糊折扣系数。

### 2.6 复用时必须比较所解决的问题

本领域与跨领域复用采用相同的检查：比较旧方法与新方案的目标、约束、可用信息、输入／输出、参与者或环境条件（含适用时的攻击者能力）及成功判据。不同数据集、模型、任务名称或应用行业，不自动构成实质不同的问题。

| 问题关系及适配证据 | 问题适配价值 R |
|---|---:|
| 实质问题相同；或只有名称／场景变化，没有新的适配关系 | 0 |
| 问题实质不同；为明确新障碍完成必要适配，作用可核验 | 1.0 |
| 问题实质不同；建立非显然的变量、约束或信息路径对应，解决旧方法不能直接处理的障碍 | 1.5 |
| 问题实质不同；以实质推导与验证完成问题重构，形成明确的新处理路线 | 2.0 |

有新问题适配时，必须记录“旧问题→新问题→旧方法不能直接处理的原因→新增对应／设计→作用证据”。没有这些证据时不能仅凭“应用不同”领取 1—2 分；若差异是否成立仍影响定分，按第2.1／2.5节处理状态，不把未知强写成相同或不同。

R 属于同一主要贡献的评价，不是次要创新 J。若同一问题适配已经用于确定 C3—C8 等结构／任务适配档位，应记为已包含（R_included），不得再叠加一次；计算见第5节。对所有复用路径同时执行源模块评价，不能只为跨领域方法检查新颖性和复杂性。

## 3. 创新类别与子类分值

A、B、C、D、E、P六条路径互斥地选出每项贡献的主类，**不按字母顺序表示水平高低**。A、D、E、P 采用固定基准分及原子类上限；B、C 采用**基础分区间 [L,H]**和**未追加问题适配时的子类上限 U0**。先确定类别，再在该区间内按0.5步长选择 S0，不可为追求分数倒推类别。C8基础区间按本版调整为6.0–7.0，其他子类基础分不变。

**所有表中的「上限」只限制对应贡献单独成立时的分数，不限制整篇论文加上独立次要创新后的总分。**对B/C：未被原档位包含的问题适配修正为ΔR=R−R_included；该贡献的上限为U_i=min(U_class,U0+ΔR)，B的U_class=5，C的U_class=7。A/D/E/P则使用表列固定上限。主导贡献计算完毕后，符合独立性要求的次要贡献奖励J≤1在**主导类别上限之外**叠加；整篇论文只受10分总上限与第2.3节主线限制M约束。

**B/C 区间内定分必须说明源想法／模块的价值：**

- **新颖性：**按比较时点及实际最接近先例，说明源想法是成熟常规做法，还是具有较新且非平凡的表示／推断思想。首次使用的名号、文献年份近或术语新不能替代机制比对。
- **必要技术／概念复杂性：**考察关键约束、依赖关系、推导和协调难度，以及这些难度是否为解决问题所必要。模块数量、参数量、代码长度、算力和实现繁琐不等于这一复杂性。
- **迁移适配深度与实际作用：**说明该模块在新系统中承担的必要角色，何种理解、选择、兼容或推导使复用成立；不能只罗列源模块的优点。
- 常规、简单直接的复用取区间低端；源模块新颖性或必要技术复杂性突出，且本方案确实消化并有效运用了这些性质时，可以取高端。两维分别记录，不要求两者都高；二者都有依据时可更充分支持高端，仍不能突破本子类区间。
- 上述判断只决定 S0，不另设“源模块新颖性分”或“复杂性分”；R评价问题是否不同及适配关系，J评价独立次要贡献，三者不得对同一事实重复计分。源工作的原创归属仍属于源作者，不能把其完整发明算成本方案独立原创。复杂模块若只是黑盒接入，不能仅凭其复杂性取高端。
- A/D/E/P 的复用分析也须记录这些因素，但不得借此给其固定分值另加奖励；若贡献实质属于组合或适配，应改按 B/C 的成立条件定类。

### 3.1 A类：局部细节创新，主导贡献上限2分

新增范围有限，未改变整体结构或主线中的关键机制。小改动若改变关键机制，应继续判断D类。

| 编号 | 子类与适用条件 | 基准分 | 主导子类上限 U0 |
|---|---|---:|---:|
| A1 | 新增很轻微的局部预处理、后处理或边界规则；作用明确，但可直接构造，主算法几乎不变 | 0.5 | 1.0 |
| A2 | 对单个非核心处理、预测或推断细节提出新计算规则；影响局限于一个局部步骤 | 1.0 | 1.5 |
| A3 | 增加一处新的任务相关局部约束、校正或调节规则；仍由已有原理直接构造 | 1.5 | 2.0 |
| A4 | 形成完整的局部处理单元，设计有一定原创性，但不改变整体结构与关键机制 | 2.0 | 2.0 |

### 3.2 B类：本领域组合创新，主导贡献上限5分

要素已用于目标任务，组合关系有新增，但连接和运算仍采用已知形式。

| 编号 | 子类与适用条件 | 基础分区间 [L,H] | U0 |
|---|---|---:|---:|
| B1 | 目标任务的常见模块形成常规串联、并联或拼接；各自功能基本独立，且组合存在可确认新增 | 2.0–2.5 | 2.5 |
| B2 | 按互补功能组合已有要素，明确围绕一个技术问题；交互方式仍常规 | 2.5–3.0 | 3.5 |
| B3 | 将目标任务内不同技术路线的要素作非惯常组合，需要兼容处理，但处理规则本身已知 | 3.0–3.5 | 4.0 |
| B4 | 对已有要素作非直观的选择与流程安排，形成连贯方案；仍无新结构规则或核心机制 | 3.5–4.0 | 4.5 |

区间高端依第3节的源想法新颖性、必要复杂性和适配作用取值，不能只凭稀少或模块数量多抬分。B1 可高于 A4 的固定分，但须明确组合的实际新增；大类字母不构成强制高低顺序。

本领域旧模块用于实质不同的问题，按第2.6节计入1—2分的问题适配价值；仍是已知形式的组合时可留在B，该主导贡献的U最高5。若出现非平凡任务转换或结构重组，则按实际关系进入C，不因其来源在目标领域内而拒绝C，也不为突破B上限强行升类。

R数值不能替代分类边界检查：若支持R的对应／重构本身已满足C3/C4等必要条件，应重新定类并记录已包含价值；不能为保留额外R而故意停留在较低子类。

### 3.3 C类：跨任务迁移与结构适配，主导贡献上限7分

#### 3.3.1 方法迁入：按障碍解决与任务重构定类

C1/C2 处理外部方法的直接迁入；C3/C4 的非平凡任务对应同时适用于本领域和跨领域迁移，C5—C8 也不按来源排斥领域内适配。学科距离不直接决定分数。评审先比较新旧问题及限制，再判断新增对应。仅“首次把X用于目标任务”不构成进入C3/C4的充分条件。

| 编号 | 子类与适用条件 | 基础分区间 [L,H] | U0 |
|---|---|---:|---:|
| C1 | 有可确认的外部首用或非等价移植，但映射基本直接，未针对目标任务的特有障碍提出新关系；并非换名或等价替换 | 2.0–2.5 | 2.5 |
| C2 | 明确目标任务约束，为外部方法建立直接、可预期的任务对应或必要接口；核心方法基本不变 | 2.5–3.0 | 3.5 |
| C3 | 针对清晰的目标任务障碍建立**非显然**的对象、约束或判别对应，解释旧做法为何不适用；主要保留源机制 | 4.0–4.5 | 5.5 |
| C4 | 以实质推导的任务转换／信息路径重组解决核心障碍，形成新处理路线；核心计算法则仍来自已有方法，未达到D | 5.0–5.5 | 6.5 |

**强制边界：**

- 先判断是不是**真正的新增**。新术语、换应用、把通用算子换个名字、已有映射的直接代入，可能为0分或A/B类，不能自动得到C1。
- **首用本身最高C2，不自动获得问题适配分。**仅换应用或名称时R=0。若证据支持实质不同问题的直接必要适配，可以在C2内计入R；是否达到C3/C4，另看非显然对应／任务重构的必要条件。来源距离和“量子／DNA／混沌”等名称不决定区间取值；源模块实际新颖性和必要复杂性按第3节核验。
- C3/C4必须逐项写出“旧障碍→迁移前不能直接解决的原因→新增对应→可验证作用”。只写“提高准确性／鲁棒性／安全性”不够。
- 如果迁移实质上**创造了新的核心表示、估计、处理、优化、预测或决策规则**，按D类；如果还形成新的**基本建模／表示原则**，考虑E8；不能因来源是已有方法就强行压在C类。
- “距离”只用于扩展查新：既要查目标任务的近邻分支，也要查源领域的同构形式。首次的证明责任仍由第2.1节承担。

#### 3.3.2 结构与策略适配

| 编号 | 子类与适用条件 | 基础分区间 [L,H] | U0 |
|---|---|---:|---:|
| C5 | 为明确目标任务约束重新设计局部连接、信息路径或阶段组织，超过常规接口适配 | 4.5–5.0 | 6.0 |
| C6 | 围绕核心问题重新组织表示、信息输入、训练或推理结构，形成有必要性的针对性设计 | 5.0–5.5 | 6.5 |
| C7 | 重新组织多个关键环节，使输入、核心处理、反馈、输出等关键阶段在结构上协调；内部机制仍主要沿用已有方法 | 5.5–6.0 | 7.0 |
| C8 | 独立性较强的整体结构／策略，关键结构选择均由同一障碍导出，但尚无新的核心计算机制 | 6.0–7.0 | 7.0 |

**C8的6.0、6.5、7.0分别对应由证据支持的区间低、中、高端。**选7.0须证明：整体结构具有独立的新求解体系；关键结构选择均由统一障碍导出且存在必要相互依赖；最近先例不能经常规模块替换或简单接口适配得到基本等价的整体方案；关键结构关系已有可核验的机制证据。仅以“范式转变”“统一”“复杂系统”命名或实验增益大，均不足以直接取7.0。

迁移与适配不是两份贡献，**同一创新事实只能匹配最高成立子类**。仅修改输入尺寸、损失权重、常规噪声增强、训练轮次、学习率、普通连接方式，不自动进入C5—C8；这些变化也不应通过包装成“整体训练框架”得到更高分。

C3—C8 的区间已包含其定义所要求的任务对应／结构适配。若“问题不同”的证据就是支持该档位的同一适配，R_included=R、ΔR=0；不是再加1—2分。只有证明另有尚未被档位或区间取值计入的问题适配价值，才能令其R_included=0并追加；必须逐项列明不同证据和理由。不能仅把同一设计改写两次，就把已包含价值标成未包含。

对端到端学习系统、生成式或其他多阶段任务，须具体比较**信息何时进入系统、经过什么状态、在哪里被处理／观测／输出，以及各阶段如何依赖**。只有新组织而无新关键计算规则时仍属C；产生不可约的新耦合机制才进入D。

### 3.4 D类：核心机制创新，主导贡献上限8分

必须确认存在**新的关键计算规则**，并明确该规则改变了目标系统或方法解决核心问题的方式。来源可以是自主提出、本领域旧部件形成的新耦合，或对外部思想进行任务化重构。

| 编号 | 子类与适用条件 | 基准分 | 主导子类上限 U0 |
|---|---|---:|---:|
| D1 | 在既有主机制内，为核心障碍加入一条不可还原为常规调节的规则，实质改变**核心处理／推理／恢复／检测中的关键状态、判决或依赖关系** | 6.5 | 7.5 |
| D2 | 提出完整的新核心机制，其主要计算关系具有独立新增；整体问题建模仍沿用已有范式 | 7.0 | 8.0 |
| D3 | 用新的条件依赖、联合状态或约束关系，重构原先分离的关键环节；这种耦合不能化约为普通串联、共享损失或并行拼接 | 7.5 | 8.0 |
| D4 | 对核心问题形成独立、自洽的新机制，其关键计算由同一新规则体系导出，而非常规改动集合 | 8.0 | 8.0 |

**D1的附加门槛（防止训练技巧虚高）：**

1. 必须写出新旧方法各自的**核心关系**：关键状态如何计算／信息如何处理或恢复／输出或判决规则如何确定；不能仅对比代码模块名。
2. **一般损失项、损失权重、训练日程、噪声采样、数据增强、优化器替换、常规可微近似，默认不满足D1。**它们按A/B或确有非平凡结构组织时的C类定分。
3. 如果训练方法本身建立了不可由原目标直接得到的**新估计或决策机制**，且可说明其在目标任务核心处理、信息传递或判决中的必要作用，可按D类；“训练方法”这个形式本身不构成降档理由。
4. 拥有多种已有模块并不排斥D3/D4。应审查它们之间新增的**条件依赖和闭环计算**；但仅把新训练目标导致的数值梯度变化叫作“更新关系改变”，不能取得D1。

机制可以位于数据处理、表示、学习、优化、推理、检测、控制、反馈、恢复或安全建模等环节。少量代码、简洁公式或新的约束关系同样可以构成D类；复杂度、网络层数和论文影响力不加分。

### 3.5 E类：基本原理与范式创新，含理论创新，主导贡献上限10分

E类不是“出现定理”“名为新范式”或“论文影响大”的同义词；应比较真实的基本命题、变量定义、假设强度、表示原则和推导。局部证明使用E1—E7及相应上限。

#### 3.5.1 理论与证明

| 编号 | 子类与适用条件 | 基准分 | 主导子类上限 U0 |
|---|---|---:|---:|
| E1 | 对已有结论给出非平凡的新证明，但贡献局部，未形成重要新工具或新结论 | 2.5 | 3.5 |
| E2 | 新证明引入可复用的局部推理工具，超出换写法 | 3.0 | 4.0 |
| E3 | 提出新的局部定理、定量关系或有限范围理论结论，证明含实质新增 | 4.0 | 4.5 |
| E4 | 首次严格证明与核心问题有关的重要局部性质，但尚未覆盖主线研究的完整性质 | 5.0 | 6.0 |
| E5 | 首次对主线中的关键性质建立完整、非平凡的理论保证，覆盖**明确的声明范围** | 6.0 | 7.0 |
| E6 | 对已有重要理论显著推进界限、放宽关键假设或扩展适用条件，包含新推理 | 7.0 | 8.0 |
| E7 | 提出新的重要理论关系或可复用的证明方法，对核心问题形成系统认识 | 8.0 | 8.5 |

E1的固定基准与B1的基础区间是本体系的分值约定，不意味着所有新证明都比所有组合有用。旧结论的常规代入／等价改写为0分；定理数量、证明长度与符号复杂度均不加分。

#### 3.5.2 基本原理、基础理论与范式

| 编号 | 子类与适用条件 | 基准分 | 主导子类上限 U0 |
|---|---|---:|---:|
| E8 | 建立与先前路线不可等价的**基本问题建模、表示或求解原则**，并由此导出可操作的不同技术路线 | 8.5 | 9.5 |
| E9 | 建立重要的新基本原理；或在合理而明确的假设下，对目标研究领域的**基础问题**给出非平凡、具有决定性的界限、不可实现性或最优性结论 | 9.0 | 10.0 |
| E10 | 建立原创统一框架，由同一基本原则连贯导出此前分立的方法或理论性质 | 9.5 | 10.0 |
| E11 | 对明确的核心基础问题给出突出原创且闭合的原理／理论解答，关键建模与推导均有实质贡献 | 10.0 | 10.0 |

**E8的必要条件：**不能只出现“首次端到端”“生成时处理”“使用外部模型”等路线标签。须指出不同于先前工作的**基本建模对象、表示关系、信息载体或推断原则**，证明它不只是相同问题下的架构改造；并展示该原则如何导出技术路线。仅形成新的关键计算关系时可为D3/D4，而不必硬升E8。

**E9及以上的必要条件：**

1. 研究的是对领域基本认识有决定意义的**基础问题**，而非某个特殊实现、某个网络或人为限定的弱模型。
2. 证明的量词、假设、参与者或攻击者能力、任务约束、判定条件和结论范围必须逐一核验。若仅适用于受限类别，应先按E3—E7的实际结果评价，除非该受限类别本身就是有独立基础意义的问题。
3. 结论必须相对于最近先前工作**非平凡**。假设中隐含结论、沿用已知概率界的机械代入或常规“鲁棒性界”不能进入E9。
4. 仅有“provably”“impossibility”“optimal”等标题词，或通过过强假设使结论显然成立，**绝不自动进入E9**。
5. 没有定理形式的新基本原理可以按E8—E11评价，但必须有同等清楚、可反驳的建模逻辑；纯理论工作不要求额外实验或算法。

#### 3.5.3 新路线的防拆碎核验

在评价使用全部已有部件构成的新路线时，必须额外回答：

- 先前工作是否已存在**同一信息流、目标变量和联合关系**？仅逐件已有不足以判为重复。
- 新路线中哪个**不可或缺的对应或计算依赖**使旧方法第一次能够解决该类问题？
- 若删去该关系，整条路线是否退化为已有方法的常规拼接？若是，说明这条关系是新增的；若否，可能只是包装。
- 将所有部件分别换回“最相近先例”，还能否得到同一技术思想？若可以，不得因历史影响力而抬分。

据此可能判为C7/C8、D3/D4或E8，**不预先锁定经典论文应得的分数**。

### 3.6 P类：问题定义、威胁建模与新认识，主导贡献上限7.5分

本路径处理**问题形式化本身**的原创性，尤其是提出新的任务目标、约束或信息条件、适用边界、风险／失效机制，或此前被遗漏的重要认识。它不是缺少算法贡献时的补偿分。

| 编号 | 子类与适用条件 | 基准分 | 主导子类上限 U0 |
|---|---|---:|---:|
| P1 | 给出有限但非等价的问题划分、失败条件或评价视角，具有明确判别意义；仍属局部认识 | 2.0 | 3.0 |
| P2 | 正式定义一个重要的具体子问题或（适用时）威胁设置，明确参与者／攻击者能力、约束和成功判据，与已有定义有实质差异 | 3.5 | 4.5 |
| P3 | 揭示旧任务／问题／威胁模型遗漏的**系统性障碍、失效条件或关键矛盾**，建立非平凡、可验证的新问题形式化 | 5.0 | 6.0 |
| P4 | 对核心任务假设或求解目标形成**深刻且自洽的重新建模**，用有力的反例／分析改变问题应如何被提出或检验；尚未达到E类基本原理／理论结论 | 6.5 | 7.5 |

P类的**加分门槛不是“第一个提出新问题／攻击名字”**，而是旧模型无法自然覆盖什么、为何重要、定义是否自洽、新认识产生什么可以检验的不同判断。仅更换任务／威胁参数、添加一组测试、列出新数据集或把已知失败重命名，可能是0分或低档局部贡献。

新问题／威胁模型可以用理论推导、结构性反例或充分具体的系统案例核验，不强制新防御算法。**后续论文引用量不是P4的必要条件或加分条件。**未来影响未知时，以比较时点能够核查的逻辑实质为准。

**P与其他类不叠加同一事实：**从新问题／威胁定义直接派生的普通求解或攻击实现不能再算独立补充贡献；若另有确实独立的新求解或攻击核心机制，按D类评价。若证明了具有决定性的基础不可能性定理，可考虑E9，但**不是**“P4＋E9”累加。

## 4. 类别边界

| 边界 | 较低类的新增 | 进入较高类的必要条件 |
|---|---|---|
| 重复／A、B、C | 换名、常规算子、旧过程直接移植 | 相对最近先例有不可等价的真实新增；否则0 |
| A与B | 单一步骤或局部单元 | 新增两个以上已有部件间的组合关系，但尚无新关键机制 |
| B与C | 采用已知形式选择／排列目标任务的已有部件；不同问题可计R但B主导贡献最高5 | 非平凡任务对应、结构适配或超出常规连接的信息路径；本领域来源也可成立C3—C8 |
| C1/C2与C3/C4 | 只会直接移植、常规适配 | 指出目标任务特有障碍及非平凡对应；**不按迁移距离升档** |
| C与D | 调整训练／推理结构，核心计算规则仍已知 | 提供不可化约的新关键状态、条件依赖、估计、处理、恢复或判决机制 |
| D与E8 | 既有范式内提出新机制或新的技术架构 | 同时建立不可等价的**基本建模／表示／求解原则**并由其导出路线 |
| P1/P2与P3/P4 | 新场景、局部威胁形式或任务定义 | 揭示既有模型遗漏的系统问题或重设核心安全问题的逻辑 |
| P与D/E | 新问题、威胁、评估目标或安全认识 | 另有独立核心机制才进入D；独立基本原理／充分有力的基础理论才进入E |
| E1—E7与E9—E11 | 新局部定理、有限假设下的性质保证 | 在清楚、非平凡的假设下解决**基础层面**问题，结论范围与声称一致 |

跨领域工作要明确**原方法何处不适用、变化了哪条规则或任务对应，以及为什么与目标任务的障碍直接相关**。如果缺少原始证据或最近先例仍可能改变类别，按第2.1节返回暂定或无法定分，不凭印象“抬高”或“压低”。

## 5. 总分计算

### 5.1 先计算每项有效贡献候选

本版严格区分**贡献单独成立分数**与**整篇论文总分**。每项有效贡献先各自分类、各自计算上限；当其中一项成为主导后，其上限才记为`U_main`。**`U_main`不能用于截断后续的独立次要奖励。**

- **S0**：B/C在对应的基础区间[L,H]内按第3节选择；A/D/E/P取表列固定基准分。
- **R**：第2.6节的问题适配价值，仅用于B/C复用贡献，取0、1.0、1.5或2.0。
- **R_included**：当前贡献的同一问题适配已经在子类或S0中体现的部分；只允许`R_included=R`或`R_included=0`，后一种需列出与S0和定类不同的证据。R=0时两者均为0。
- **ΔR=R−R_included**：该贡献内部尚未被重复计入的问题适配修正，最多2.0；不属于独立次要奖励J。
- **U0**：该贡献表列子类上限。B/C有`U_i=min(U_class_i,U0_i+ΔR_i)`，其中B的`U_class=5`、C的`U_class=7`；A/D/E/P的`U_i=U0_i`，且R、R_included、ΔR均为0。
- **S_i=min(U_i,S0_i+ΔR_i)**：第i项有效贡献**单独成立时的分数**，尚未加入其他贡献。

从服务论文实际主线、承担关键作用的有效独立贡献中，选择`S_i`最高者为主导贡献`m`；原先被称为“次要”的贡献若`S_i`更高，必须改选主导并重算。若多个候选`S_i`相同，可以选`U_i`最高者；仍有并列时须交代选择依据。主线实际上不成立时，先按最强有效贡献确定暂定主导，再使用第5.3节的`M=4`限制全篇总分。

记`S_main=S_m`、`U_main=U_m`。**只有S_main受U_main限制。**其余贡献仅当确实独立、有效且直接补充论文主线时才可按第5.2节计算J；任何已用于主导类别、S0高端或R的事实都不能再次作为次要贡献。不能借用其他贡献的U来改变S_main，也不能为了规避定类规则而故意隐藏更强贡献。

**主导切换与分数：**主导的判定仍依据`S_i`，而不是依据预期整篇分数；但新版取消总分按主导上限U_main再次封顶。因而，在贡献独立性、主线状态及其余条件不变时，**单纯增加有效独立贡献或提高贡献自身分数，不再因切换到较低类别上限而导致旧公式中的总分下降**。若实质审查改变了贡献独立性、有效性或主线成立性，必须据实重新评价，不能以算术单调性代替学术判断。

本领域已有模块不因来源而失去R；跨领域来源也不自动取得R。问题相同且无新机制时不追加R，仍可按实际源模块评价在已成立子类区间内选择S0。B/C区间高端、R和J必须由不同创新事实支持，不能重复奖励同一适配设计。

### 5.2 次要创新合计最多增加1分，且不受主导类别上限截断

次要贡献须是有效、独立且直接补充主线的算法、理论或问题定义新增，未用于确定主导类别、区间高端或R。下列内容不算独立次要创新：参数选择、常规工程实现、更多实验、验证主要创新的消融或证明、同一机制拆出的多个子步骤。P类同一问题／威胁定义的反例和普通求解／攻击实例不能重复计入。

每项次要贡献先按第5.1节作为独立候选计算其`S_i`，再换算增量：

| 次要贡献的单独分数 S_i | 增量 j_i |
|---|---:|
| 0或未通过有效性核验 | 0 |
| 大于0且≤2.0 | 0.5 |
| ≥2.5 | 1.0 |

**所有次要贡献的总奖励`J=min(1.0,Σj_i)`，最多1分。**该奖励在主导贡献的`S_main`**完成类别封顶后**叠加；不再受到`U_main`、`U0`或主导`U_class`的截断，即使使整篇总分高于A/B/C/D/E/P任一类别上限也合法。它仍受整篇10分上限及主线限制M约束。

**注意：**这里的“额外”是指奖励`j_i`额外计入，不是把次要贡献原本的`S_i`直接与`S_main`相加。两项0.5增量即用完奖励；出现十项有效创新也不能超过J=1。资料不明且可能改变主导选择时，先处理`assessment_status`，不能把未知贡献填0充作已判断无效。

### 5.3 最终公式与封顶层次

```text
# Each candidate contribution i is assessed independently first.
# B/C candidate:
Delta_R_i = R_i - R_included_i
U_i = min(U_class_i, U0_i + Delta_R_i)  # B: 5; C: 7
S_i = min(U_i, S0_i + Delta_R_i)

# A/D/E/P candidate:
R_i = R_included_i = Delta_R_i = 0
U_i = U0_i
S_i = min(U_i, S0_i)

# Select the main contribution m by maximal eligible S_i.
# Tie-breaking follows section 5.1.
U_main = U_m
S_main = S_m

# Only independent, valid and non-overlapping secondary contributions.
j_i = 0   if S_i == 0 or the contribution is invalid / non-independent
j_i = 0.5 if 0 < S_i <= 2.0 and the contribution qualifies as secondary
j_i = 1.0 if S_i >= 2.5 and the contribution qualifies as secondary
J = min(1.0, sum(j_i))                 # Exclude main contribution m

# Whole-paper limits; U_main is deliberately NOT applied again.
M = 4.0 if the mainline fails else 10.0
S = min(10.0, M, S_main + J)
0 <= S <= 10.0
```

上式的`U_i`只约束第i项贡献单独成立的分数，`U_main`只用于`S_main`；**最终总分S绝不再取`min(U_main,...)`**。例如B主导5.0加J=1可得6.0，C主导7.0加J=1可得8.0，D主导8.0加J=1可得9.0；达到这些总分不意味着主导类别升级到另一类别。E类与其他类别一样允许额外J，但整篇总分仍不能超过10.0。

**M=4属于全篇主线完整性限制，并非A/B/C/D/E/P的类别上限**，因此本次不移动M的位置：主线不成立时，即使`S_main+J>4`，仍以4分截断；若未达到4分也不以4分保底。查新不充分或核心材料不足时`assessment_status=insufficient`、`S=null`；全部贡献核验为无效时`S=0`，不执行无证据的奖励。

在**现有基础分、允许的R和新增C8区间**下，可达到的类别级最高值如下（仅为算术边界，假定主线成立且存在足够独立的有效次要贡献，并非每篇该类论文必然达到）：

| 主导类别 | 可达到的S_main最高值 | J最多1后可达到的整篇最高值 |
|---|---:|---:|
| A | 2.0 | 3.0 |
| B | 5.0 | 6.0 |
| C | 7.0 | 8.0 |
| D | 8.0 | 9.0 |
| E | 10.0 | 10.0 |
| P | 6.5 | 7.5 |

**特别说明P类：**P4的固定基础分是6.5，虽然该子类表列`U0=7.5`，现行规则未给P类单独追加R的途径，因此`S_main`的实际可达最高值仍为6.5；7.5只能在J=1且主线成立时达到。不能把表列U0误当成必然可得的主贡献分。

所有分数按0.5步长。报告必须写明[L,H]／固定基准、S0及依据、R、R_included、ΔR、U0、U_class（适用时）、各项`U_i`和`S_i`、选定主导的`U_main`和`S_main`、次要贡献的各项j、J、M、最终S，以及**主导贡献封顶和全篇封顶分别发生在何处**。问题适配可以提高主要创新分，但不能借此突破该主导类别上限；**在主线成立且不考虑全篇上限截断时，总分超过主导类别上限只可能来自合规的独立次要奖励，并不意味着更高类别的必要条件已得到满足。**

## 6. 执行与输出

执行顺序：

1. 记录用户指定的`target_task`及任务边界，确认被评论文版本、资料范围、比较时点及论文声称的贡献类型：算法／理论／问题建模。
2. 提取拟主线；列出**最小不可约新增单元**，归并从属或重复贡献。新旧关系应写成可比对的变量、公式、信息流或威胁定义。
3. 执行第2.1节的强制联网查新与三轮有实质差别的反证复核；**未完成就停止数值评分**。
4. 对照最近原文确认实质新增，按第2.5节分别核验算法、理论或问题定义的成立条件。
5. 逐项应用第4节的边界测试，优先解释**为何不是更低档**，再判断更高档的必要条件是否满足。
6. 按第3节比较源模块新颖性和必要复杂性选择区间内S0，按第2.6／5节核对问题适配及重复记账；先计算每项独立贡献的S_i和U_i并选主导，再将合格次要奖励J加到已经封顶的S_main之外，最后只应用全篇10分与M限制。
7. 输出查新记录、原文位置、归类反证、有效性结果、分数理由、评估状态与待核验事项。

输出可采用Markdown或JSON，但必须包含：

| 字段 | 内容 |
|---|---|
| `rubric_version` | `1.7.0` |
| `target_task` | 用户本次指定的研究领域、任务或问题；必要的边界及邻近等价问题范围 |

**强制输出约束：**

- **未联网或未完成多轮复核：**`assessment_status=insufficient`，`score.S=null`；不能用记忆写“估计7分”。
- **核心论文方法／定义／证明无法取得：**`assessment_status=insufficient`，`score.S=null`。
- **已完成查新且主要创新可确认，但存在非决定性争议：**可给`provisional`数值，逐项标明分数可能变化的具体原因。
- **全部贡献经核验为重复或无效：**`complete`且`score.S=0`；这与资料不足时的`null`严格区分。

| 原称主导B2低端2.5、次要C6低端5.0 | 必须改选C6主导S_main=5，B2若真正独立则j=1，最终6 | 6.0 |
| C3高端4.5和独立E1原得5.5，再加入独立B4高端4.0且R=1未包含 | B4的S_main=5改为主导，另两项J合计最多1；新总分6.0，**不再发生原版的降分** | **6.0** |
| 拟主导D2被充分对照证明不承担核心作用，剩余有效贡献C5低端 | D2不计；C5主导4.5，J=0 | 4.5 |
| 核心方法或定义、必要比较材料缺失 | `assessment_status=insufficient` | `null` |
| 没有实际联网，或只检索一轮 | `assessment_status=insufficient` | `null` |

**防滥用提醒：**不给训练策略因为冠以“新机制”名称就判D1，也不给普通迁移因为宣称“跨领域首次”就判C3；同样不能为了总分跨越7分而拆分主导创新领取J。**超过某个主导类别上限的整篇总分，不等于主导创新达到了更高类别门槛。**所有变更均须保留独立的文献与机制依据。

## 8. 合理性、证据与后续校准

### 8.1 通用化修订的依据与适用范围

本版沿用v1.6.0的任务通用化框架与严格查新、有效性、去重要求，并修改主导／次要贡献的计分关系。以下是继续适用的原则：

1. 复用已有模块时，本领域与跨领域均比较所解决的问题；实质不同的问题适配价值R为1—2，问题相同为0。
2. 两类复用均考察源想法的新颖性、必要技术复杂性及实际运用，支持区间内S0高低；不把源原创归本方案，也不奖励无必要的繁琐。
3. B主导贡献上限为5，C主导贡献上限为7；C8基础区间由6.0–6.5扩展为6.0–7.0；其他子类基准分与上限保持v1.6.0数值。
4. 先完成主导贡献自身的类别封顶，再额外加入真正独立的次要奖励J（最多1分）；**不对加J后的整篇分数重新施加主导类别上限**，但保留10分总上限与M限制；禁止R、S0高端和J重复计同一事实。
5. 旧报告保留其旧版规则和分数。修改公式与C8基础区间不自动证明任何真实论文应涨分或降分；重评仍须指定任务、锁定比较时点并核验具体问题、原文和独立次要贡献。

除本次明示调整的C8区间外，具体区间宽度与U0的数值继承v1.6.0的项目操作化约定，不声称来自跨领域专家统计。后续可按第8.4节独立校准，不能以某篇论文的期望分数倒推阈值。

### 8.2 主流科研判断与本规范的关系

CVPR和NeurIPS官方审稿指引明确承认**新思想、新问题建模、已有方法的非平凡组合、理论认识或负面发现**可以是学术贡献，并要求以具体先例支持“缺乏创新”的指控。但是主流审稿中的**原创性、技术正确性、影响力与论文总体推荐**并非同一项量。本规范只把其“原创性判断原则”作为参考，**不声称已证明10分制与会议审稿分数相等或可互相换算**。

对具备技术有效性的论文，后续影响力很大但原创机制普通，不应因知名度加分；一篇新问题提出后没有成为热点，也不因后见之明自动失去其在比较时点真实存在的原创性。

### 8.3 候选锚定集：由目标任务确定，只规定核对问题，不预设目标分

校准候选须在**指定目标任务后**选取真实、可取得原文的论文或技术报告；不能预先固定某一领域的代表作，跨任务更不能直接沿用其他领域的数值评分。以下仅规定每种候选需要检查的分类边界，**不是对任何真实论文的预设类别或分数**。

| 候选类型 | 需要核对的分类问题 |
|---|---|
| 重复或低增量的负对照 | 改名、更换数据／应用、常规调参、旧模块直接代入，何时应判0分或A类 |
| 本领域组合工作 | 已有部件是否形成真正新增的组合关系；B1—B4与C类的分界 |
| 外部方法迁入 | 直接移植、任务接口适配与非显然问题对应的区别；C1/C2与C3/C4的分界 |
| 结构与策略适配 | 局部信息路径、整体结构和关键环节协调是否确有新增；C5—C8与D类的分界 |
| 核心机制创新 | 是否出现不可化约的新状态、计算规则或条件依赖；D1—D4与普通训练技巧的分界 |
| 理论与基本原理 | 新证明、新理论关系和基础建模原则分别满足什么门槛；E1—E7与E8—E11的分界 |
| 问题／威胁模型创新 | 旧问题遗漏了什么，是否有非等价定义、反例或新成功判据；P1—P4及其与D/E的分界 |

应事先纳入**负对照、中档对照与高档候选**，避免只选择知名或方法复杂的论文。每个目标任务都要依据其真实发展史重新选文、核对投稿时点、取得原文并执行三轮查新；候选集只能用于之后的独立校准，不能反向决定某篇论文应该得到多少分。

原v1.5.0所列的图像水印候选论文保留在历史版本中，**不构成本通用规范的默认锚定集**。

### 8.4 建议的独立校准流程

1. **盲于预期分数。**先锁定本版规则和论文集合，再请至少3名熟悉目标任务不同子方向的评审独立查新、写出新增关系、选择子类与区间。不要先展示本文示例中的预期类别，也不把名气当作依据。
2. **同时检查可复核的顺序关系。**例如“仅有远距离首用、没有针对目标任务障碍的新增”不应高于“确实改变核心处理／推理机制”；“换损失权重”通常不应高于“新状态耦合”。若有反例，按机制核实，不硬改分值。
3. **记录分歧位置。**分开统计主类分歧（C/D/E/P）、子类分歧、数值评分差异；至少报告得分中位数、极差或四分位距，以及评审之间分差超过1分的比例。
4. **先修判定语句，后修数值。**若分歧来自“新计算关系”“基本问题建模”等门槛不清，补充可判定条件；只有跨论文、跨评审存在稳定偏差，才调整基准分／有效上限。
5. **检查现有公式是否扭曲比较。**分别观察主线M=4的封顶、主导贡献U_main截断、独立J的使用频率及10分总封顶；不能仅根据锚定论文有名就给予类别或独立性判定豁免。
6. **冻结检验集。**修订时用一组论文，完成后用另一组未参与修改的论文做回测，检查规则是否泛化，避免对少数熟悉的代表作过拟合。

**当前状态声明：**v1.7.0沿用v1.6.0的通用目标任务框架，已改变主导／次要贡献的最终公式以及C8基础分区间；**尚未完成多个领域专家的独立数值标注与一致性实证校准**。文档／公式校验和独立场景审查不能替代这种跨领域实证校准。下列既有参考资料支持一般评价原则，不作为本规范1—2分、5／7上限或区间宽度的实证来源。

### 8.5 可核查的依据

- [CVPR 2026 Reviewer Guidelines](https://cvpr.thecvf.com/Conferences/2026/ReviewerGuidelines)：重视真正的新概念与知识贡献；批评缺少新意须指出具体先前研究。
- [NeurIPS 2026 Reviewing Guidelines](https://neurips.cc/Conferences/2026/ReviewerGuidelines)：原创性可体现为新问题框架、评价指标、技术组合、理论新认识或负面结果，且根据贡献类型判断。
- 按目标任务选择的原始论文、正式出版页面和可查的作者预印本，用于校准候选与边界测试；**论文摘要、题目、期刊等级和后续影响本身不足以完成每篇论文的数值评分查新**。
