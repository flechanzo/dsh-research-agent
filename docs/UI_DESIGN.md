# Research Workspace UI 设计与实现

日期：2026-10-28（Asia/Shanghai）

## 信息架构

面板按“项目状态 → 当前路径 → 当前操作 → 科研内容 → 分支关系 → 节点详情”排列：

1. 顶部身份条显示自动科研标题、阶段、状态、活动分支和工作区。
2. 状态条显示加载/执行中的反馈和选中节点的祖先路径。
3. 阶段路径允许只读选择历史节点；选择节点不会推进科研状态。
4. 面板内导航只调用 scrollIntoView，用于定位科研内容、分支关系和节点详情。
5. sticky 操作区承载当前阶段主要动作，保留上传、确认/写入、反馈、拒绝和节点查看的原有语义。
6. 内容、分支图/列表和节点详情继续复用既有组件及数据模型。

## 响应式策略

- 根面板保持单一纵向滚动容器；Markdown 表格、代码块和 DAG 画布只在自身需要时横向滚动。
- 560px 以下：状态条和操作区换行，主要按钮占满可用宽度，详情网格保持可读折行。
- 561–760px：操作区改为上下布局，避免操作按钮被状态信息挤出视口。
- 125%/150% 缩放下按钮最小高度为 30px，阶段路径可横向滚动，长标题使用 overflow-wrap:anywhere。
- DAG 画布保留缩放、平移、定位、折叠、列表降级和本地布局记忆；异常环通过访问集合停止遍历。

## 视觉与可访问性

- 仅复用 DSH --dsw-* 变量、主题状态色、圆角和阴影。
- 当前阶段和当前节点使用业务主色边框；状态仍使用宿主 success/warn/error 色阶。
- 操作区使用半透明背景和边界，不遮挡根滚动条；危险动作保持“拒绝并生成新方案”语义。
- 导航、阶段路径、DAG 节点和列表行都有可访问名称与 :focus-visible 状态；进行中和错误使用 aria-live/role=alert。

## 保持不变

自定义 Preset、论文上传与摘要、问题提炼、文献检索、创新性评估、多角色评审、人工检查点、研究成果、分支 DAG、历史导航、计划预览/写入以及 revision 恢复均保留。没有伪造引用、费用统计或执行日志。
